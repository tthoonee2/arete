# Credits

## Mountain geometry

The alpine mountain mesh in `src/mountain-assets.html` was generated for Arête using Tripo API (generation task `c26ac33d-e236-4e2b-aefa-fb07e9e5ca96`). The embedded height grid and world-space rock/snow material were created for this integration. No external mountain textures are used.

## Three.js GLTFLoader

`src/vendor/GLTFLoader.js` is the official Three.js r128 loader. Three.js is distributed under the MIT licence; see `src/vendor/THREE-LICENSE.txt`.
